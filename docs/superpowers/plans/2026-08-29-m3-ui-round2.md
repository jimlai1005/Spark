   → 200，**36MB** JSON。形狀：
   ```json
   {"leaderboardRows":[{"ethAddress":"0x…","accountValue":"58675737.76",
     "windowPerformances":[["day",{"pnl":"…","roi":"…","vlm":"…"}],["week",{…}],
       ["month",{…}],["allTime",{…}]],
   ```

   {"time":ms,"user":"0x…","action":{"type":"agentSendAsset",…},"block":n,"hash":"0x…","error":null}]}`。

3. 既有 HL 封裝：`src/spark/publicapi/hl.py` HLGateway——`portfolio()`(66)、
